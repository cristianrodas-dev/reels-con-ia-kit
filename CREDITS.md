# Créditos

Este kit adapta ideas y metodología de proyectos abiertos. Gracias a sus autores.

| Proyecto | Licencia | Qué tomamos |
|---|---|---|
| [instagram-agent-skill](https://github.com/Jakeschincariol/instagram-agent-skill) — Jake Schincariol | MIT | Fórmulas de gancho, puntaje de ganchos y metodología de auditoría (adaptadas al español en `guion/ganchos.json`, `guion/gancho.py` y `skills/reels-guionista`). |
| [social-media-skills](https://github.com/charlie947/social-media-skills) — Charlie Hills | MIT | Ideas: análisis de un Reel de referencia, reglas de palabra clave para el pedido, control de calidad con puntaje. Sin código copiado. |
| [marketingskills](https://github.com/coreyhaines31/marketingskills) — Corey Haines | MIT | Ideas: lista de señales de texto hecho con IA, principios de lead magnet. Sin código copiado. |

## Herramientas de terceros

- **[Remotion](https://www.remotion.dev)**: gratis para personas y empresas de hasta 3 empleados; empresas más grandes necesitan una [licencia de empresa](https://www.remotion.dev/license). Revisa su licencia antes de usarlo comercialmente.
- **Montserrat** (`video/public/fonts`): SIL Open Font License 1.1.
- **Efectos de sonido** (`video/public/sfx`): sintetizados con ffmpeg para este proyecto; de uso libre bajo la licencia MIT de este repo.
- **ElevenLabs / Azure / Kokoro / Edge TTS**: servicios o modelos de terceros, cada uno con sus propios términos. Las voces que generes son tu responsabilidad.
